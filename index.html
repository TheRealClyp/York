Why York


Built for how you actually code


Familiar structure, honest performance, zero ceremony. Here is what makes York worth your time — and what it deliberately skips.








Fast by design


A friendly pipeline compiles source straight to native output in seconds. Built for edit-run-fix loops, not coffee breaks.








Arena memory


Stack-like arenas with stash semantics. Fast, predictable, and trivially safe — no garbage collector, no pauses, nothing hidden.








Single native binary


York compiles down to true native code. Drop the binary anywhere and it just runs — no runtime, no shared libs to chase.








Verified downloads


Every artifact on this site is pinned to a SHA-256 checksum served in the same place. What you see is exactly what runs.








Familiar syntax


Typed parameters, methods, enums, loops. The structure you already know — no boilerplate, no ceremony, no learning cliff.








One-command install


A tiny installer puts york on your PATH in one line. Nothing else to install, nothing left dangling, nothing hidden.










The language


Written the way you already think


Value semantics by default. When you read from an arena you get a copy — mutation is explicit. Click through the tabs.

struct Player {
    float pos;
    float hp;
}

impl Player {
    void damage(float amount) {
        this.hp -= amount;
        if (this.hp < 0.0) { this.hp = 0.0; }
    }
}




enum Dir { North, East, South, West }

void describe(Dir d) {
    switch (d) {
        case Dir.North: println("up");   break;
        case Dir.South: println("down"); break;
        default:       println("sideways");
    }
}




// a packed little game loop
Arena<Player> players = new Arena(1000);
players.push(Player { pos: 1.0, hp: 100.0 });

for (Player p : players) {
    p.damage(10.0);
    println(p.hp);
}

FAQ


Questions, answered



Do I need anything else installed?

No. York ships as a prebuilt native binary — the installer just puts it on your PATH. Nothing else to install, nothing dangling.





How does York handle memory?

Arena memory with value semantics: data lives in fast stack-like arenas, you read copies, and mutation is explicit. No garbage collector, no ceremony.





Is York production-ready?

0.2.55 is early but real: structs, impls, enums with switch, arrays, and file I/O all compile fast to native code. More libraries are on the roadmap.





Can York run in the browser?

Soon. The browser backend is in progress, and it compiles the same York source you run natively.





How do I uninstall York?

Delete the install directory — %LOCALAPPDATA%\Programs\york on Windows, ~/.york on macOS and Linux — and remove the PATH entry the installer added. Two steps, done.





Is this website written in York?

Yes. This page is generated by a York program — the whole layout, every word, and the scripts. The generator lives in this site's repository.





Is York open source?

This distribution ships free, prebuilt binaries. The compiler source stays private.
