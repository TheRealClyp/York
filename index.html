GC · runtime · magic

Built for how you actually code

Syntax you already know, performance you expect, zero magic under the hood.

Familiar syntax

Java and JavaScript style: typed params, this, method calls, for loops — no boilerplate, no ceremony.

No classes, no clutter

Plain structs for data, impl blocks for methods, traits for behavior. Composition beats inheritance, always.

Arena memory

Stack-like arena allocation with stash semantics. Fast, predictable, and trivially safe — no GC pauses, ever.

Single native binary

York compiles straight to C and then to your platform's native code. Drop the binary anywhere; it just runs.

Fast compiler

A friendly pipeline that goes from source to native output in seconds — designed for edit-run-fix loops, not coffee breaks.

WebAssembly on deck

Compile the same York source to WebAssembly for the browser. One language, native speed, everywhere.

One-command install

A tiny installer drops york on your PATH. Download it from this page, or pipe one line to your shell. No Rust toolchain, no giant SDK.

Enums & switch

Type-safe enums with first-class switch statements. Compile-time checked variants, compiled straight to native C switches.

Honest errors

Errors point at the problem with the surrounding code — not a wall of cryptic template vomit.

Write it the way you already think

Value semantics by default. When you read from an arena you get a copy — mutation is explicit.

// hello in York
public static void main(String[] args) {
Arena<Player> players = new Arena(1000);
players.push(Player { pos: 1.0, hp: 100.0 });

for (Player p : players) {
    p.damage(10.0);
    println(p.hp);
}
}

struct Player {
    float pos;
    float hp;
}

impl Player {
    void damage(float amount) {
        this.hp -= amount;
        if (this.hp < 0.0) { this.hp = 0.0; }
    }
}

Enums and switch

Declare types you care about, then branch on them — safely and fast.

// directions
enum Dir { North, East, South, West }

void describe(Dir d) {
    switch (d) {
        case Dir.North:
            println("up");
            break;
        case Dir.South:
            println("down");
            break;
        default:
            println("sideways");
    }
}

enum Status { Ok, Warn, Err }

Status s = Status.Ok;

if (s == Status.Ok) {
    println("all good");
}

Questions, answered

Do I need Rust, the JDK, or anything else installed?

No. York ships as a prebuilt native binary — the installer just puts it on your PATH. Nothing else to install.

How does York handle memory?

Arena memory with value semantics: data lives in fast stack-like arenas, you read copies, and mutation is explicit. No garbage collector, no borrow-checker ceremony.

Is York ready for production?

0.1.0 is early but real: structs, impls, traits, enums with switch, arrays, and file I/O all compile to native C. The WASM backend and more libraries are on the roadmap.

Can I compile York for the browser?

Soon. The WebAssembly backend is in progress, and it compiles the same York source you run natively.

How do I uninstall York?

Delete the install directory (%LOCALAPPDATA%\Programs\york on Windows, ~/.york on macOS and Linux) and remove the PATH entry the installer added. Two steps, done.

Is York open source?

This distribution ships free, prebuilt binaries. The compiler source stays private.
